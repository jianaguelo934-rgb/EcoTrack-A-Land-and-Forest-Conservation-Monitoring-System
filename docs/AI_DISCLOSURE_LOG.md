## 1. Reference Benchmark Examples

The following two examples illustrate the depth of prompting and human verification expected by evaluators:

**Example A — Code Generation & Reactive State Management**
*Date & Milestone:* 2026-10-24 | *Week 3 (Mobile MVP Development)*
*AI Tool & Model:* Google Gemini 2.5 Pro
*Member Responsible:* Juan Dela Cruz (Lead Mobile Developer)
*Exact Prompt Provided:* "Act as a senior Flutter developer. I need a ChangeNotifier provider class named 'ClinicQueueProvider' for an app serving rural health clinics. It should store a list of ClinicTicket objects (id, patientName, queueNumber, status: waiting/serving/completed, estimatedWaitMinutes). Include methods to addTicket, callNextTicket, and calculateTotalWaitTime. Include proper null safety and error handling."
*AI Output Summary:* Generated a complete ChangeNotifier Dart provider with model classes and reactive state mutation methods.
*Human Refinements & Edits:* Replaced the AI's in-memory mock list with local persistent storage using shared_preferences; added custom validation to prevent duplicate queue numbers; refactored method names to conform to team conventions.
*Key Learning Takeaway:* Learned how notifyListeners() triggers reactive rebuilds in Flutter Consumer widgets and how to handle asynchronous storage writes safely.

**Example B — UI Layout Assembly & Constraint Debugging**
*Date & Milestone:* 2026-10-28 | *Week 3 (UI Layout Assembly)*
*AI Tool & Model:* GitHub Copilot Chat (VS Code)
*Member Responsible:* Maria Santos (Lead UI/UX Designer)
*Exact Prompt Provided:* "I am getting 'A RenderFlex overflowed by 38 pixels on the bottom' inside my SingleChildScrollView containing a Column with an Expanded ListView.builder. How do I fix this layout constraint issue in Flutter?"
*AI Output Summary:* Explained that Expanded inside an unbounded scrollable creates vertical height conflicts; recommended shrinkWrap: true with NeverScrollableScrollPhysics().
*Human Refinements & Edits:* Applied shrinkWrap: true and tuned card padding from 16px to 12px to optimize layout density on smaller screens.
*Key Learning Takeaway:* Understood Flutter's constraint protocol: 'Constraints go down, Sizes go up, Parents set positions'.
